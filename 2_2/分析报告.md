# 基于 Elastic Net 的 Netflix 用户电影评分预测分析

## 一、分析目的

本实验使用 Netflix Prize 用户评分数据，预测某个用户对某部电影的1～5星评分。研究问题是：加入用户身份、电影身份和评分时间后，Elastic Net 能否比始终预测训练集平均评分更准确？

## 二、数据来源和抽样

使用随机种子42，从1～17770号电影中无放回抽取80部电影。每部电影保留全部评分，若超过2000条，则以种子42+电影编号随机抽取2000条。该抽样限制了热门电影的权重，不是从全部评分中等概率抽样，结论仅对应此实验子集。

最终取得 **60,988条评分、46,594位用户、80部电影**。日期范围为2000-01-05至2005-12-31；平均评分3.4938星，标准差1.1559星。每条记录包括 user_id、movie_id、rating、date。脚本检查评分范围，并确认没有重复的用户—电影评分对。

## 三、特征与预处理

目标变量为 rating。输入为用户编号、电影编号、评分年份，以及月份的正弦、余弦编码。编号通过独热编码转换为类别特征，不能将编号大小解释为喜好程度。独热编码删除每列的第一个类别作为参考类别。训练折内出现次数不足5次的类别合并为低频组；未知类别映射到已有低频组，没有低频组时按全零编码处理。

随后使用 StandardScaler(with_mean=False) 对稀疏特征进行尺度调整，避免中心化把稀疏矩阵变成大规模稠密矩阵。所有编码和缩放均放入 Pipeline，每折只在该折训练部分拟合，验证集和测试集不参与预处理参数的学习。没有使用从完整数据计算的用户平均分或电影平均分，因此不存在这类目标泄漏。

以固定随机种子42随机划分80%训练集、20%测试集，分别为48,790条和12,198条。再在训练集上采用5折交叉验证选择参数。用户可以出现在训练集和测试集中，故本实验是随机留出评分的评估，不是按时间预测未来评分的评估。

## 四、Elastic Net 模型

目标函数为：

$$\min_{b,\beta}\frac{1}{2n}\sum_{i=1}^n(y_i-b-x_i^T\beta)^2+\alpha\rho\|\beta\|_1+\frac{\alpha(1-\rho)}{2}\|\beta\|_2^2.$$

其中 alpha 控制惩罚强度，rho 对应 l1_ratio。L1项可使部分系数为零，L2项使系数更稳定，截距不受惩罚。采用 ElasticNet 加 GridSearchCV，以便每折重新拟合整个预处理流程。

alpha 候选为0.0001、0.0003、0.001、0.003、0.01、0.03、0.1、0.3；l1_ratio 候选为0.1、0.5、0.9。交叉验证仅根据验证 MSE 选参，不根据测试集结果改参数。最优 alpha 为 **0.001**，最优 l1_ratio 为 **0.9**，交叉验证 RMSE 为 **1.0398星**。

该模型主要学习用户的整体打分倾向、电影的整体评分差异和时间趋势，是加性线性模型。它没有直接学习用户与电影之间的交互或 SVD 的潜在偏好因子。

## 五、测试集结果

| 方法 | RMSE（星） | MAE（星） | R² |
| --- | ---: | ---: | ---: |
| 训练集平均评分基准 | 1.1559 | 0.9748 | -0.0001 |
| Elastic Net 原始预测 | 1.0355 | 0.8274 | 0.1973 |
| Elastic Net 限制到1～5星 | 1.0352 | 0.8267 | 0.1978 |

主要指标采用原始预测。相比平均分基准，Elastic Net 的测试 RMSE 降低了 **10.41%**，说明电影和用户等特征提供了一定的预测信息。MAE=0.8274表示平均绝对误差约0.83星。R²=0.1973表示测试集评分变异中约19.7%被模型解释；R²不是分类准确率。

将预测值截断到[1,5]是单独列出的固定后处理规则，不用于选参。由于真实评分都在此区间，把预测投影回区间不会增大单条记录的绝对误差或平方误差。

![评分分布、预测与残差](analysis.png)

模型对不同真实分值的预测仍有明显重叠，低分容易被高估，高分容易被低估，体现了预测向平均水平收缩。单凭这些特征难以准确还原每个人对某部影片的特定偏好。

## 六、系数分析

编码后的特征数为403，其中374个系数绝对值大于1e-8，视为非零。L1惩罚确实产生了部分零系数，但非零数本身不能证明模型预测更好，仍需看验证和测试误差。

以下为标准化系数绝对值较大的8个电影类别：

| 电影编号 | 标准化系数 |
| --- | ---: |
| 2269 | -0.1855 |
| 12125 | 0.1551 |
| 12026 | 0.1259 |
| 8282 | 0.1225 |
| 11903 | 0.1018 |
| 6510 | 0.0939 |
| 17178 | 0.0929 |
| 16376 | 0.0854 |

正系数表示在其他条件相同且沿用本编码参数化的情况下，对预测评分的贡献为正，负系数则相反。这些是标准化后的系数，不是电影平均评分，也不能直接当作切换电影类别时的评分变化量。独热编码、截距与惩罚共同决定系数的数值，不应赋予单个系数因果解释。

![系数路径](coefficient_path.png)

路径图显示最优模型中绝对值最大的10个系数，固定最佳 l1_ratio，改变 alpha。总体上惩罚越强，系数越靠近零，部分系数会精确归零；存在相关特征时，单个系数不一定严格单调。

## 七、结论与局限

本实验中，Elastic Net 相比平均评分基准降低了预测误差，但其解释能力仍有限。测试集中 **66.67%** 的评分来自训练集未见过的用户，这些记录无法学习独立的用户偏好，只能依靠电影、时间以及低频组信息；测试集未见电影比例为0.00%。本报告没有宣称实现了可靠的新用户个性化推荐。

数据只有80部电影，并限制每部电影最多2000条评分，不能代表全量 Netflix Prize 的效果。随机留出也不能证明模型在未来时间段、新电影或其他平台上的性能。后续可扩大电影样本，按时间切分评估，并加入仅从训练数据学习的交互或潜在因子。这里按作业要求保留 Elastic Net 作为核心模型。
